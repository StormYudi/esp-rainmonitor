# RainMonitor

把电脑的运行状态，放到一块圆圆的小屏幕上。

插上就能看 CPU、显卡、内存和网络，配色和 Windows 11 任务管理器一样。开机后自动工作，插着 USB 走数据线，拔掉就改用蓝牙。

## ✨ 能做什么

- 实时查看电脑占用和网速
- 开机自动后台运行，不用每次打开软件
- USB 和蓝牙自动切换
- 充电和电量显示在屏幕右上角

## 🚀 第一次使用

准备好 RainMonitor 副屏，以及一台 Windows / macOS / Linux 电脑。

### 1. 刷入屏幕固件

1. 关机后按住 **BOOT**，再短按电源键（屏幕保持黑屏是正常的）
2. 打开 [ESP-Mosaico 网页刷机](https://mosaico.espressif.com/firmware-update/)，选择 `dist/rainmonitor-0.1.0.bin`
3. 松开 BOOT，重新开机

屏幕亮起后，左上角是 RainMonitor，中间是时间。还没连上电脑时会提示等待数据。

### 2. 安装电脑端

Windows 用户双击 `rainmonitor-windows-amd64.exe`（ARM 电脑用 `arm64` 那个）。

1. 选择 **1）安装系统服务**
2. 在弹出的权限窗口里点允许
3. 看到「系统服务（运行中）」就完成了

之后开机就会自动采集，把数据发到屏幕上。

macOS / Linux 运行下载好的 `rainmonitor`，同样选安装即可。

只想先试一下、不装服务：选 **3）在当前窗口前台运行**。

### 3. 连上屏幕

插上 USB，或打开电脑蓝牙。屏幕连上后就会开始刷新。

## 🎛️ 屏幕按键

| 按键 | 作用 |
| --- | --- |
| **BOOT** | 清空历史曲线 |
| **AI** | 调节亮度 |
| 点按格子 | 放大这一项的详情 |

## 🧹 卸载

再打开电脑端程序，选 **2）卸载系统服务**，在权限窗口点允许即可。

---

RainMonitor 会在后台安静工作。装好之后，把它放在桌角就行。
